# Posicionamento

## O erro comum

"Faço qualquer coisa com IA" não vende. O cliente não sabe o que pedir,
cada projeto vira sob medida, o preço fica difícil de defender e você
nunca reaproveita nada.

## A estrutura recomendada: 1 nicho principal + 1 base horizontal

```
                ┌─────────────────────────────────────┐
  VERTICAL      │  Advocacia (nicho de entrada)        │  ← onde você vira referência
  (profundo)    │  petições, triagem, prazos, clientes │
                └─────────────────────────────────────┘
                ┌─────────────────────────────────────┐
  HORIZONTAL    │  Automações genéricas                │  ← serve qualquer empresa
  (reutilizável)│  atendimento WhatsApp, e-mail, docs  │
                └─────────────────────────────────────┘
```

- **Horizontal**: blocos que funcionam para qualquer negócio
  (atendimento, extração de documentos, relatórios). São seus "tijolos".
- **Vertical**: os mesmos tijolos montados para um nicho, com a linguagem,
  os documentos e as dores dele. É aqui que o preço sobe, porque você
  fala a língua do cliente.

Comece com **um** vertical. Advocacia é uma boa escolha: muito documento
repetitivo, profissionais que cobram por hora (tempo economizado = dinheiro)
e muitos escritórios pequenos sem time de tecnologia.

## Frase de posicionamento (rascunho para ajustar)

> Ajudo escritórios de advocacia de pequeno e médio porte a produzir
> petições e atender clientes em uma fração do tempo, com IA treinada nos
> modelos do próprio escritório — e o advogado sempre revisando antes de
> protocolar.

## Escada de ofertas

Facilita a primeira venda (baixo risco para o cliente) e cria caminho
para contratos maiores.

| Degrau | Oferta | Objetivo |
|---|---|---|
| 1. Entrada | Diagnóstico de automação (pago ou gratuito curto) | Entender dores, gerar confiança |
| 2. Piloto | 1 solução do catálogo, 30 dias, escopo fechado | Provar resultado rápido |
| 3. Core | Solução completa + mensalidade de manutenção | Receita recorrente |
| 4. Expansão | Novas automações no mesmo cliente | Aumentar ticket |

## O que você vende de verdade

Não venda tecnologia ("usamos o modelo X com RAG"). Venda:

- **horas economizadas** por semana;
- **padronização** (todas as petições no padrão do escritório);
- **velocidade de resposta** ao cliente final;
- **menos erro** (prazo perdido, documento faltando).
